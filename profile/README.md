## What we build

**Epiow** is the **AI-native Collaboration Web OS** on Sylphx Platform: a ChromeOS-class browser workspace with installable Manifest-isolated apps for every collaboration unit that must work together.

| | |
|--|--|
| **Collaboration unit** | One Platform-authenticated tenant per company, school, government, NGO, studio, family, or crew |
| **Shell** | Lock, launcher, windows, dock, search, settings, lockdown |
| **Pay** | Manifest app `epiow.workforce.pay` — payroll run → calculate → payslip or bank artifact |
| **Leave** | Manifest app `epiow.workforce.leave` — request → approve → balance |

Hong Kong statutory packs remain depth on Pay, not the product's sole name.

---

## For whom

- Commercial teams that install workforce apps (seed pair: Pay and Leave) and complete granted work across apps.
- Institutional and informal units that need lockdown, audit, and PWA-installable apps on the same tenant.
- Agents that operate the OS under grants with the same oracles as humans.
